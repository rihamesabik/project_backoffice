# CodingHub - Plateforme d'Administration

![CodingHub Banner](https://via.placeholder.com/1200x400/0d1b2a/3b82f6?text=CodingHub+Admin+Dashboard)

##  À propos
CodingHub est une plateforme d'administration moderne pour la gestion de challenges de programmation, participants, soumissions et classements.

##  Fonctionnalités
- **Authentification sécurisée** avec interface futuriste
-  **Tableau de bord** avec statistiques 
-  **Gestion des participants** avec profils détaillés
-  **Challenges de programmation** par catégories
-  **Système de soumissions** avec évaluation
-  **Classement** des participants
-  **Paramètres d'administration** complets
-  **Support multi-langues** (FR, EN, AR)

##  Technologies
- **Frontend** : HTML5, CSS3, JavaScript (ES6+)
- **UI Framework** : Bootstrap 5.3
- **Icons** : Font Awesome 6.4
- **Charts** : Chart.js
- **Hébergement** : Netlify
- **Version Control** : Git & GitHub
